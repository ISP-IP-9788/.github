<h2>一、双ISP到底是什么</h2>

<p>普通住宅IP的地址段注册在一家运营商名下，这家运营商做路由调整或局部检修，整段可能跟着波动。双ISP指同一段地址同时注册在两个本地运营商名下（比如一家有线电视商加一家电信商），流量可以从两条路走，单边故障时另一条顶着。对需要长时间在线的业务，这个冗余有实际意义。</p>

<p>要注意区分：真双ISP是 ASN 层面的双注册；有些服务商只是接了两家上游，地址段本身还是单归属，那不叫双ISP，叫双上游，抗故障能力差一截。买之前让对方提供两个 ASN 号，自己查。</p>

<h2>三、购买时必须看的五个配置项</h2>

<p>1. 两个 ASN 分别归属哪家运营商，能否提供 ASN 号自行查验；2. 故障切换是自动还是手动，切换过程掉不掉线——自动切换几秒内完成的和要工单处理的，体验差很远；3. 带宽是双路叠加还是单路备用，叠加才能跑出更高吞吐；4. IP 是否保号，续费后是否同一地址；5. 是否支持指定州或城市。五项都明确，才配得上双ISP的溢价。</p>
